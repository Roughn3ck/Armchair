## TCN — robots.txt + noindex Added (2026-08-18)

Kris correctly noted the preview URL isn't truly private — anyone with the URL can open it. Added:
- `robots.txt` with `User-agent: * / Disallow: /`
- `<meta name="robots" content="noindex, nofollow">` + `googlebot` noindex in index.html

This keeps it out of search engines, but the URL is still technically accessible to anyone who has it. True privacy would need Cloudflare Access (auth) or a custom domain with access control — flag for later if needed.

**Deploy auth fix (clean method):** The `cfat_` token contains special chars that break shell quoting. Reliable deploy pattern:
```bash
printf '%s' "$CLOUDFLARE_API" > /tmp/cf_token.txt
export CLOUDFLARE_API_TOKEN="$(cat /tmp/cf_token.txt)"
wrangler deploy
```
This avoids the intermittent 9106 auth errors caused by shell quoting mangling the token.
